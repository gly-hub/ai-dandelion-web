# 功能编辑器布局重构方案

## 当前问题
- 布局不固定，流程切换时体验不连贯
- 预览阶段仍显示对话框，占用空间

## 目标布局

### 整体结构
```
┌─────────────────────────────────────────────────────────┐
│                    顶部导航栏                              │
├──────────┬──────────────────────────────────────────────┤
│          │                                              │
│  流程栏   │              内容区域                         │
│          │                                              │
│  1.产品   │  ┌────────────────────────────────────┐    │
│  2.技术   │  │                                    │    │
│  3.代码   │  │   根据流程显示不同内容              │    │
│  4.预览   │  │                                    │    │
│          │  └────────────────────────────────────┘    │
└──────────┴──────────────────────────────────────────────┘
```

### 流程1-3: 左右分栏布局
```
┌──────────┬─────────────────┬──────────────────┐
│  流程栏   │   文档/代码面板  │    AI 对话框      │
│          │                 │                  │
│  ✓产品   │  产品方案内容    │   对话历史        │
│  2.技术   │                 │                  │
│  3.代码   │  [采用按钮]      │   输入框          │
│  4.预览   │                 │                  │
└──────────┴─────────────────┴──────────────────┘
```

### 流程4: 全屏预览
```
┌──────────┬──────────────────────────────────────┐
│  流程栏   │                                      │
│          │                                      │
│  ✓产品   │                                      │
│  ✓技术   │          预览画布                     │
│  ✓代码   │                                      │
│  ●预览   │                                      │
│          │                                      │
└──────────┴──────────────────────────────────────┘
```

## 实现步骤

### 1. 调整主布局结构
- 将流程步骤栏从 sidebar 移到内容区左侧
- 固定流程栏宽度（建议 200-240px）
- 右侧内容区自适应

### 2. 条件渲染内容区
- `step === 'preview'`: 只渲染预览画布（100%宽度）
- `step !== 'preview'`: 渲染文档面板（左）+ 对话框（右）

### 3. CSS 调整
- 移除现有的三栏网格布局
- 使用固定的两栏网格：流程栏 + 内容区
- 内容区根据流程使用嵌套网格或单列

### 4. 组件调整
- `FunctionGenerationConsole`: 在预览阶段不渲染
- `renderPlanningWorkspace`: 根据 step 调整布局模式
